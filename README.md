# Voice Teleprompter

A teleprompter that runs in the browser and scrolls to follow your voice.

Open it at **https://robertbacker.github.io/teleprompter/** in Chrome (laptop or Android) or Edge.

- Paste a script or open a `.txt` file. Text in `[square brackets]` is shown as a cue and not read.
- **Follow my voice** mode uses on-device speech recognition where the browser supports it, otherwise the browser's online service.
- **Steady scroll** mode scrolls at a set speed and works in any browser.
- Scripts and settings are stored only in your own browser. Nothing is uploaded.

Keys: Space start/pause, ↓/PgDn next line, ↑/PgUp previous line, +/− text size, M mirror, F full screen, E edit.
